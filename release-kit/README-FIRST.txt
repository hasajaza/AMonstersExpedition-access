A Monster's Expedition Access - screen reader accessibility mod

Install in three steps:

1. Close the game. Extract this whole zip to any folder, for example your Downloads folder.
2. Open the extracted folder and double-click Install.cmd (select it and press Enter).
   The installer finds your game folder and copies everything into it.
   If it cannot find the game, it asks you to paste the game folder.
3. Start the game. You will hear:
   "Accessibility mod ready. Press F1 for the key list."

Manual installation instead of Install.cmd:
copy everything inside the folder named "files" into the game folder
(the folder that contains the game's .exe), and allow Windows to replace files.

Keys: see KEYBOARD.md. Press F1 in the game to hear all of them, and F2 to change any of them.

Screen readers: JAWS and NVDA work through Universal Speech. Without a screen reader the Windows
voice is used.
JAWS users: if JAWS is silent inside the game, open JAWS Settings Center, choose Unity Player,
go to Miscellaneous and set Sleep Mode to disabled.
NVDA users: nvdaControllerClient32.dll must be next to the game's .exe. The 32 in the name
matters.

If the mod is silent, press F12 in the game and send BepInEx\LogOutput.log.

This mod is for the 32-bit Windows build of A Monster's Expedition and uses BepInEx 5 (win_x86).
