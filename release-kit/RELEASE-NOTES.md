A screen-reader accessibility mod for A Monster's Expedition. Keyboard or controller, no mouse
needed. Works with JAWS and NVDA, and falls back to the Windows voice if no screen reader is
running.

## Install

Download **AMEAccess-1.2.0-complete.zip** below. It contains everything, including BepInEx.

1. Close the game. Extract the whole zip to any folder, for example Downloads.
2. Open the extracted folder and run **Install.cmd** (select it and press Enter).
   It finds your game folder and copies everything in. If it cannot find the game, it asks you
   to paste the folder.
3. Start the game. You should hear: "Accessibility mod ready. Press F1 for the key list."

Press **F1** in game to hear the keys, one per press. Press **F2** to change any of them.

If you already have BepInEx 5 win_x86 installed, use **AMEAccess-1.2.0-mod-only.zip** instead
and extract it into the game folder, the one containing the game's .exe.

## New in 1.2.0

**The game can now be played start to finish on a controller.** The left stick moves your
monster and moves through menus, the right stick moves the review cursor, the left stick click
chooses and the right stick click opens the game's menu. Thirty-six actions can be put on
buttons, in three sets reached by holding a shoulder. Press **F7** to set it all up from inside
the game: step through the actions and push the stick or press the button you want.

DualSense, DualShock and Xbox pads set themselves up. Anything else is a minute with F7.

**Tiles can be reported by sound instead of words.** Press **F6** to switch between speech,
sound and both. The sounds are the game's own — a splash for water, a footstep for land, a tap
on the trunk for a tree — played in the direction of the tile, so you can sweep the cursor
across an island and hear its shape. Names and plaques are always spoken.

**The warp map is properly readable.** Destinations are grouped — towards the main route, main
route, friends, not visited, visited — and each says how far, which way, whether you have been
there, and whether it is on the game's main route. **F4** tells you whether you are on that
route and, if not, which postbox lands you nearest to it.

**Exhibits are only exhibits.** Benches, huts, friends, trophies, the ferry and plain props are
named for what they are instead of all being counted as exhibits.

Blocked moves say what blocked them, and why: water, a boulder, too high to climb, or the wrong
side of a log.

## Help

JAWS users: if JAWS is silent inside the game, open JAWS Settings Center, choose Unity Player,
go to Miscellaneous and set Sleep Mode to disabled.

If the mod is silent, press **F12** in game and send BepInEx\LogOutput.log.
If something on screen is not in the survey, stand next to it and press **F8**.
If a controller is not working, press **F5**.
